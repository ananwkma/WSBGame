# Art Assets — WallStreetBets Game

This folder contains all the art assets for the game. Replace any file here
with your custom artwork using the exact same filename. The game will use your
art automatically.

## Rules
- Keep the exact filename (including uppercase/lowercase)
- Use PNG format only
- Match the dimensions listed below (or the game will scale your art)
- Do not rename folders

## Note on Colors
The game applies a 4-color Game Boy grayscale filter to all visuals.
Your artwork will be filtered to 4 shades of green/gray. Design with this in mind —
high-contrast art (strong darks and lights) survives the filter best.
