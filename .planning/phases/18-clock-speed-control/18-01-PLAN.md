  <files>src/hooks/useMarketClock.ts</files>
  <action>
    Rewrite useMarketClock.ts to accept a speed parameter and scale the interval:

    ```typescript
    import { useEffect } from 'react';
    import { useGameStore } from '../store/useGameStore';

    const BASE_INTERVAL_MS = 2000;

    export function useMarketClock(speed: 1 | 2 | 5 = 1) {
      useEffect(() => {
        const intervalId = setInterval(() => {
          const state = useGameStore.getState();
          if (state.gameStatus !== 'playing') return;
          state.tickMarket();
        }, BASE_INTERVAL_MS / speed);

        return () => clearInterval(intervalId);
      }, [speed]);
    }
    ```

    Key changes from the current file:
    - Function signature: `useMarketClock()` → `useMarketClock(speed: 1 | 2 | 5 = 1)`
    - Hardcoded `2000` → `BASE_INTERVAL_MS / speed` where `BASE_INTERVAL_MS = 2000`
    - Empty dep array `[]` → `[speed]` so the interval is torn down and recreated whenever speed changes
    - Default parameter `= 1` preserves backward compatibility if called with no argument

    Do NOT change the `useGameStore.getState()` pattern — it intentionally avoids stale closures on the store.
    Do NOT add any suppression logic based on speed value — tickMarket must fire at the full rate regardless of speed.
  </action>
