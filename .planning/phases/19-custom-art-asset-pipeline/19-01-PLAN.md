    Write a one-time Node.js script at `scripts/generate-placeholders.mjs` that generates all 22 PNG files and then run it.

    The script should use the `canvas` npm package or a simple approach: generate a raw PNG binary using a minimal PNG encoder (no npm install needed — write a small buffer-based PNG generator using Node.js `zlib` for DEFLATE compression), OR use the `sharp` package if it is already in package.json.

    Check package.json first: if `sharp` or `canvas` is already installed, use that. Otherwise, write a self-contained minimal PNG generator using Node.js built-ins (zlib + Buffer).

    **PNG spec for each placeholder:**
    - Background: dark gray (RGB: 64, 64, 64) — maps to a visible mid-palette color under the 4-color Game Boy filter
    - Text label: light color (RGB: 220, 219, 203) — the game's lightest palette color, survives the filter
    - Label text: the asset name (e.g., "MENDYS", "GURU_HAPPY_IDLE", "LOCKSCREEN_BG")
    - Each image must be created at the exact dimensions below

    **Asset dimensions:**
    - endings/*.png: 112 x 84 px each (label text: the ENDING_TYPE value, e.g. "MENDYS")
    - guru/happy-idle.png: 200 x 200 px (label: "GURU_HAPPY_IDLE")
    - guru/happy-excited.png: 200 x 200 px (label: "GURU_HAPPY_EXCITED")
    - guru/sad-worried.png: 200 x 200 px (label: "GURU_SAD_WORRIED")
    - guru/sad-crying.png: 200 x 200 px (label: "GURU_SAD_CRYING")
    - lockscreen/bg.png: 180 x 400 px (label: "LOCKSCREEN_BG")
    - readit/avatar.png: 48 x 48 px (label: "READIT_AVATAR")
    - contacts/*.png: 40 x 40 px each (label: the kebab-case contact name, e.g. "WIFE", "APE-FRIEND")

    **If implementing a minimal PNG encoder without npm:**
    A minimal valid PNG can be constructed using Node.js buffers: PNG signature (8 bytes), IHDR chunk (width, height, 8-bit depth, RGB color type), IDAT chunk (zlib-compressed scanlines — each row prefixed with filter byte 0x00), IEND chunk. For the label text, draw each character pixel by pixel using a simple 5x7 bitmap font baked into the script as a constant. This is self-contained with no npm installs.

    **Alternative if a PNG library is available:** Use it — don't hand-roll if not needed.
