# WallStreetBets Trader Game

A narrative-focused, short grayscale pixel art game.

## Core Premise
The player is a retail trader sitting at a laptop, making high-stakes financial decisions based on sketchy "guru" advice, Reddit-style forums, and messages from family and friends.

## Key Features
- **First-person Perspective:** View of a laptop screen and a handheld phone.
- **Laptop (Robbinghood):** Buy/sell stocks, options (calls/puts).
- **Laptop (GuruTube):** Video advice from "investment gurus."
- **Phone (Messages):** Communication with a friend and your wife about finances.
- **Phone (r/wsb):** A Reddit-like forum for "due diligence."
- **Economics:** Starting capital of $100,000, multi-ending narrative based on performance.
- **Aesthetic:** 4-color grayscale pixel art, turn-based/event-driven gameplay.

## Technical Stack
- **Framework:** React + Vite
- **Styling:** CSS (Pixel-perfect), Canvas for specific UI elements
- **State Management:** React Context or Redux
- **Architecture:** Component-based UI-driven game loop
